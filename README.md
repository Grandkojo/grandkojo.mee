# Grandkojo's Portfolio

A modern, responsive portfolio website built with Laravel 12, featuring a clean design, admin panel for content management, and comprehensive testing suite.

## 🚀 Features

- **Portfolio Showcase**: Display projects, skills, and resume items
- **Contact Form**: Email functionality with validation and confirmation
- **Admin Panel**: Content management for projects, skills, and resume items
- **Responsive Design**: Modern UI built with Tailwind CSS
- **Comprehensive Testing**: Unit and feature tests with PHP 8 attributes
